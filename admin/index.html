Logowanie

Wpisz hasło do panelu i kod z aplikacji na telefonie. Hasło sprawdza serwer, nie ta strona, a po kilku błędnych próbach logowanie jest blokowane.

Serwer nie ma włączonego 2FA, więc wystarczy samo hasło. Zalecamy dodać sekret TOTP_SECRET w Cloudflare.

Panel zapisuje zmiany prosto do repozytorium GitHub, więc wpuszcza tylko osobę z Twoim tokenem GitHub. Nikt inny niczego tu nie zmieni, nawet gdy zna adres tej strony.

  1. Wejdź na github.com/settings/personal-access-tokens/new.
  2. Wybierz Only select repositories i wskaż tylko tymonekk.github.io.
  3. W Repository permissions ustaw Contents na Read and write (reszta zostaje bez dostępu).
  4. Ważność ustaw na krótką (np. 30 dni), wygeneruj token i wklej go poniżej.

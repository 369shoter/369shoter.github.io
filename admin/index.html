Logowanie

Wpisz hasło do panelu i kod z aplikacji na telefonie. Hasło sprawdza serwer, nie ta strona, a po kilku błędnych próbach logowanie jest blokowane.

Serwer nie ma włączonego 2FA, więc wystarczy samo hasło. Zalecamy dodać sekret TOTP_SECRET w Cloudflare.

Statystyki

Statystyki wymagają jednorazowego kroku. Serwer nie ma jeszcze klucza do GoatCountera. Zaloguj się w GoatCounter, kliknij swoją nazwę użytkownika (prawy górny róg) → API → Create new token z uprawnieniem Read statistics, a potem dodaj go w Cloudflare jako sekret GOATCOUNTER_TOKEN (szczegóły w worker/README.md).
